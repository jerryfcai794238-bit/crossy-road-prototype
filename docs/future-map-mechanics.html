進入原型的門檻

加權總分至少 3.8／5，可讀性至少 4，公平至少 3；再用固定種子短關卡驗證 4 人推擠、失誤回檢查點、AI 重搜。

進入正式地圖池的門檻

加權總分至少 4.2／5，公平至少 4，且沒有封死所有可行路線的情境。

加權分數以五項權重合計，顯示至小數一位；剛好落在 0.05 時一律進位，確保排序可重算。

First Experiment

P1：預警後動態破洞

借鑑的是「預警後改變地形」這個結構，而不是任何 Disney 的角色、關卡美術或 IP 表現。主題可換成炮彈、隕石、落石或魔法爆炸。

01

顯示落點

危險格出現明顯標記至少 1.0–1.2 秒。

02

命中地格

落點命中後才切換成破洞；不直接隨機命中玩家。

03

暫時失效

踩入或被推入破洞就失誤，回上一個安全區。

04

定時修復

破洞修復，避免領先者永久封住後方路線。

製作範圍

短關卡驗證
  • 安全區 2 排 → 動態破洞 4 排 → 安全區 2 排
  • 先做固定種子與固定落點，再測隨機生成。
  • 玩家、AI、推擠都必須使用同一份格子可走判定。

公平護欄

未通過不可採用
  • 不攻擊安全區／檢查點，不同時封死整排。
  • 任何時刻至少保留一條可行路線。
  • 不可連續鎖定同一名角色；破洞必須修復。

Mechanic Cards

候選機制：玩家看到什麼，系統要保證什麼

預警後動態破洞

P1｜4.0

危險格先亮起，命中後成為暫時無法站立的洞；推擠既可能救人，也可能害人。

系統依賴

  • 動態格子狀態、修復計時、AI 重搜、全隊共享可走判定。
  • 失誤沿用【休閒模式】個人 checkpoint 與目前位置排名。

要先證明

  • 畫面預警足夠清楚，四人不會因一發攻擊全部無解。

共享渡筏／大型載具

P2｜4.2

能同時載四人的大型平台橫渡河道；上船、等船與下船自然形成隊列壓力。

系統依賴

  • 多角色承載、相對座標、上／下船格子預約。
  • 先穩定目前漂流木「不會把人拉回中間」的世界座標規則。

公平護欄

  • 容量至少四人，靠岸安全窗可讓整隊離開，不能依出生順序固定淘汰人。

橫向掃擊物

P2｜4.0

巨浪、滾桶、擺錘或光束從一側掃過；玩家要等安全週期或搶先跨越。

系統依賴

  • 固定軌跡、入場預告、擊退或失誤判定。
  • 可用相同邏輯替換世界主題，無須另寫玩法。

公平護欄

  • 必須從畫面邊緣可見，完整安全週期不能在安全區生成。

動物群／遊行隊列

P2｜3.9

一個寬隊列橫向通過，但會保留缺口；玩家需選擇左或右的通過點。

系統依賴

  • 群體隊形、缺口生成、可達性檢查。
  • 比單純車流更容易製造橫移與推擠。

公平護欄

  • 缺口至少容納兩名相鄰角色，每輪至少有一個可達缺口。

踩踏後崩落地板

P3｜3.7

踩過後先顯示裂痕，再短暫崩落；領先者會改變後方玩家的通路。

系統依賴

  • 每格獨立狀態、延遲倒數、修復、AI 動態尋路。
  • 與動態破洞共用地格狀態，但風險更高。

公平護欄

  • 裂開後至少保留 0.8–1 秒逃離時間，且永遠有替代路。

既有三項基準

P0｜基準

車流、鐵道預警、河道載具不是新內容；它們是評估每個新機制是否更有價值的基準。

先穩定再擴充

  • 車流不可重疊；鐵道必須可讀；河道必須支援多載具與左右位移。
  • 若基準規則仍不穩，新機制只會放大問題。

Reusable Templates

不要複製關卡，複用機制模板

程式應依機制分類，美術、音效與名稱再依世界主題替換。這樣可避免每個新地圖都重寫玩法。

移動碰撞物

車流 → 動物群 → 遊行隊列。共用：方向、速度、缺口與碰撞。

預警後高速通過

火車 → 巨浪 → 光束。共用：預警、不可通過時間窗、通過實體。

移動承載物

漂流木 → 渡筏 → 飛毯。共用：承載、相對位置、出界與下船。

預警後地形失效

炮彈 → 隕石 → 落石 → 魔法爆炸。共用：落點、破洞、修復、重搜。

踩踏後延遲失效

斷橋 → 薄冰 → 腐朽木板。共用：觸發、倒數、崩落、修復。
