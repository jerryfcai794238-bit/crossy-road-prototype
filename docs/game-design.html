3 分鐘總覽

先看懂【休閒模式】怎麼玩

你和另外 3 名角色一起過馬路。120 秒倒數結束時，站得最前面的人獲勝。被撞或落水不會淘汰，但會回到上個安全區，位置與排名都會退後。

① 目標

倒數結束時，現在站得最前

排行榜只比較目前位置。跑得快不代表保得住；失誤回退後，名次立刻改變。

② 操作

W／A／S／D，每次走一格

前方有人時，不是卡住：你會推動連續隊列，讓整排角色一起向輸入方向移動。

③ 判斷

看車、河道與安全區

車和火車會撞人；河道只能踩浮木或浮萍；無樹草地是安全區，會記住你的復活位置。

Ch1 / Positioning

核心定位：把「過馬路」變成可逆轉的同場競速

👁 危險可讀

每次只看懂下一步

判斷下一格、車流節奏、火車警示與浮木去向，就能做出移動決定。

↔ 共同路線

站位不會永久阻擋

角色會形成隊列；推擠會讓前方角色同方向前進，隊列可以被疏通。

⚠ 風險交換

推人也可能害人

推擠能幫你搶先，也可能把別人送進危險落點；這是同場競速的關鍵。

Ch2 / Casual Core Loop

休閒多人核心循環

觀察 → 決策 → 移動／推擠 → 判定 → 更新是唯一閉環；每次結果都更新局勢與檢查點，再回到觀察；120 秒倒數全程運作，歸零時依角色目前位置結算排名。

Ch3 / Push Sandbox

推擠沙盒：同一條規則，三種結果

目標格有人時可向同方向推隊列；先完成落地，才判定危險。

↗ 前進方向在右⚑ 安全檢查點10 格示意

隊列、樹阻擋與落水回旗幟

旗幟格是檢查點；右側後段才有危險。最多按 4 次就能看見結果。

實作契約與驗收

觸發

方向意圖的目標格被 actor 佔用時，收集同方向、連續相鄰的隊列。

判定順序

輸入排序 → 目標預約 → 從隊列前端檢查邊界／後退下限／樹／預約 → 同 tick commit → 落地危險判定。

狀態與可見結果

成功時全隊各前進一格且不得重疊；失敗時全隊不動、保留 movementIntent，顯示最前端紅色目的格與回彈。

邊界

跳躍中的 targetGridX/Z 即為已預約格；兩人同搶一格依 (serverTick,inputSequence,actorId) 決定先到者。危險列不是 push legality 的拒絕條件。

驗收例

  • 三人連續隊列且前方空格：三人同 tick 位移。
  • 最前端為樹：零人位移，三筆意圖仍存在。
  • 推入無載具河道：先落地，【休閒模式】角色立即轉入復活。

Ch4 / Hazard Reading

危險判斷：看得懂，才值得冒險

🚗 時機

道路與鐵路

避開車體；火車非閒置時先別踏上鐵路。

≋ 載具

河道

只能落在浮木或浮萍；被帶出邊界算失誤。

⚑ 重整

安全區

無樹草地更新較前方檢查點，是下一次重新觀察的位置。

【休閒模式】簡化短關卡

起點檢查點到下一個安全區

每一排就是一格：你從最下方的起點安全區第 2 排出發；前進一次仍在起點安全區第 1 排，第二次才進入車道。兩條車道各自判定自己的車；兩條河道各自只能站在自己的浮木上。可前後左右各走一格。

你
位置：起點安全區第 2 排

道路與鐵路實作契約

觸發

角色完成落地後，進入道路列或火車列即檢查移動物件碰撞。

判定順序

先以角色碰撞寬度比對同列車體；再於 TRAIN_PASSING 時比對火車。推擠不預先跳過此判定。

狀態與可見結果

【休閒模式】角色命中後進入 Respawning；【挑戰模式】角色依傷害契約扣血或結束。畫面需清楚顯示撞擊來源。

邊界

無敵期間不重複受傷；火車警示開始不代表已碰撞，只有火車通過中的實體命中才算。

驗收例

  • 【休閒模式】角色落在車體重疊區：回 checkpoint。
  • 【挑戰模式】角色在火車警示但尚未通過時：不受傷。
  • 【挑戰模式】角色無敵時再與車體重疊：HP 不變。
河道實作契約

觸發

角色完成落地後位於 RIVER 列，或站在動態浮木上被水平帶動時。

判定順序

先檢查角色是否覆蓋浮木／浮萍；若覆蓋動態浮木，套用 direction×speed×Δt；否則判為落水。

狀態與可見結果

【休閒模式】角色落水或出界進入 Respawning；【挑戰模式】角色立即 Dead／結算。角色不可停留在無載具河面。

邊界

浮木帶動出 |worldX|>8.64 即失誤；跳躍中不做河道承載判定，落地後才判。

驗收例

  • 落在浮萍：不位移且存活。
  • 落在無浮木河面：【休閒模式】角色回 checkpoint；【挑戰模式】角色結束。
  • 浮木帶出邊界：依模式進入對應失誤狀態。

Ch5 / Casual Multiplayer

休閒模式：120 秒內把「現在」跑得最前

🏁 結算

規則與結算

【休閒模式】4 人同列起跑，120 秒是唯一自然結算。排名比較目前位置，不是歷史最遠距離，也不是存活時間。

⚑ 可逆轉

失誤與復活

【休閒模式】角色遭車撞、火車、落水或漂出邊界時，回到個人檢查點；復活後 1.0 秒無敵，排名立即依新位置回退。

⌨ 輸入

操作

使用鍵盤 W／A／S／D 向前、左、後、右移動；每次輸入一格。

實作契約與驗收

觸發

【休閒模式】角色每次落地更新 CurrentDistance = gridZ；只有 gridZ 改變時才寫入 reachedTimestamp = simulationTime，橫移不改。時間歸零時凍結操作並排序。

判定順序

落地 → 檢查危險 → 若是較前方無樹草地則更新 checkpoint → 更新目前距離／即時排名；復活後以新 gridZ 寫當下 simulation time，再更新排名。

狀態與可見結果

【休閒模式】開場為 z=0, x=[-3,-1,+1,+3]。結算排序為 CurrentDistance DESC, reachedTimestamp ASC, playerJoinOrder ASC；時間戳只比較同一目前距離的角色。

邊界

舊草地不覆寫較前方 checkpoint。復活候選永遠 z<=checkpoint.z：先在 checkpoint 同列找可用 x；無格時才依距離由近到遠找更後方草地，不能選前方。候選均需無樹、無 actor、無預約；同距離選 x 較小，半徑 6 無格則維持 Respawning 並每 tick 重試。

驗收例

  • 【休閒模式】角色從 z=12 復活至 z=6：排行榜立刻以 6 比較。
  • 【休閒模式】角色死亡於 z=12、checkpoint z=6 且同列被占：復活格必須 z<=6，名次下降。
  • 兩人先後復活至同一 z：較早寫入該 z 的 simulation time 者排名較前。
  • 橫移後同在 z=10：時間戳不變；再同時才依 join order。
AI 實作契約與驗收

觸發

AI 每 0.22 秒評估，搜尋深度至少 10 格，候選順序固定為前、左、右、後。

判定順序

排除樹、預約格、2.2 world units 內車體、非 IDLE 鐵路與無載具河格，再套用與人類相同的 push／reservation 規則。

狀態與可見結果

前進無解時，連續 3 次決策無有效前進後退一格；失敗時依固定左右順序重搜，不能左右抖動。

邊界

【休閒模式】AI 被推入危險或漂出邊界，套用同一個 checkpoint／排名流程。

驗收例

  • 前方車距不足時不跳入危險格。
  • 玩家卡位 0.66 秒後，AI 退或側移重搜。

Ch6 / Challenge Mode

挑戰模式：鏡頭持續前推下的單人生存

♥ HP 100

生命

【挑戰模式】角色 HP 100；車撞扣傷害、火車固定 70；非致命傷後 2 秒無敵。

≋ 一次失誤

河道

【挑戰模式】角色沒有復活；未站上載具或隨浮木出界，立即結束。

🦅 持續前推

鏡頭與老鷹

【挑戰模式】鏡頭不會因後退回拉；落後 3.4 格，老鷹抓取後結算。

鏡頭與老鷹實作契約

觸發

開局 Zbase=Zcamera=0（格）。每幀先推基礎線，再平滑追隨超前玩家。

判定順序

Zbase += 0.45×Δt；Ztarget=max(Zbase,playerGridZ-0.5)；α=1-exp(-4×Δt)；Zcamera=lerp(Zcamera,Ztarget,α)。再計算 rear limit 與老鷹。

狀態與可見結果

rearLimit=floor(Zcamera-3.4)；玩家不得選更後方目標。當 Zcamera-playerGridZ≥3.4，鎖輸入、停止一般傷害判定，播放 0.8–1.0 秒老鷹抓取，結束後結算。

邊界

deltaTime 先 clamp 至 0.1 秒；跳躍中以 targetGridZ 作前進意圖、以實際 position 作畫面位置。

驗收例

  • 30／60／120 FPS 靜止時，觸發時間均為 7.56 秒 ±0.1 秒。
  • 剛到 rear limit 的玩家仍可往前；老鷹開始後不可再受車撞或輸入。
生命與傷害實作契約

觸發

【挑戰模式】角色在道路或鐵路碰撞判定命中，且未處於無敵狀態。

判定順序

車撞傷害為 min(60,round(abs(Vcar)×8+10))；火車固定 70；HPafter=max(0,HPbefore-Damage)。

狀態與可見結果

非致命傷進入 2.0 秒無敵／閃爍；HP 歸零播放壓扁並結算。

邊界

無敵僅阻止再次傷害，不回復 HP；老鷹抓取不是傷害事件。

驗收例

  • 車速 4.2 命中：扣 44 HP，之後 2 秒不重複扣血。
  • HP 56 遭火車命中：HP 歸零並結束。
挑戰河道實作契約

觸發

【挑戰模式】角色落在無載具河面，或隨動態浮木漂出邊界。

判定順序

沿用河道承載檢查；失敗後不建立復活候選，直接轉 Dead。

狀態與可見結果

播放落水或漂離畫面，顯示死亡原因並結算最遠距離。

邊界

浮萍速度為 0 仍可承載；角色落地前不得提前判為溺水。

驗收例

  • 【挑戰模式】角色落在浮萍：持續遊戲。
  • 【挑戰模式】角色被推或自行落到無浮木河面：立即結束、沒有 checkpoint 復活。

工程附錄

工程規格：公式、資料與地圖

本附錄不新增或改變上方已定義的玩法規則；它提供實作、測試與工具所需的唯一技術細節。

座標、跳躍與固定更新順序

GRID_SIZE=1.2；worldX=gridX×GRID_SIZE；worldZ=gridZ×GRID_SIZE；橫向範圍 -6…+6。正式 tick：輸入排序 → reservation → push commit → 落地／危險 → respawn/dead → 排名／鏡頭／UI。

串流生成與反卡死

generateUntilZ=playerGridZ+35、removeWhenRowZ<playerGridZ-25。草地每列至少 3 格可站，至少 1 格連至前方可行入口；生成以 seed、列序、抽樣端點、最多 reroll 次數與 fallback 安全列確保可重現。道路／河道同向且速差過小時，採方向或速度補正；相鄰河道不得皆是浮萍列。

難度與物件公式

p=clamp(z/220,0,1)。Vcar=lerp(2.0,4.2,p)+random(0,lerp(1.2,2.3,p))；GapGrid=lerp(7.5,4.5,p)+random(0,lerp(4.0,2.5,p))；Ptruck=.15+.20p。VlogRaw=lerp(1.5,3.2,p)+random(0,1)，與前河速差小於 1 時加 1.2；相鄰河反向。火車：首次 idle 3–7 秒、警示 2 秒、Vtrain=38、通過後 idle 4–9 秒。

驗收清單

多人起跑與排名

  • 四名角色同一條起跑線，沒有重疊。
  • 【休閒模式】角色復活回檢查點後，排名立即按目前距離回退。

推擠與危險

  • 隊列同 tick 位移；樹阻擋時全隊停止。
  • 【休閒模式】角色回檢查點；【挑戰模式】角色依傷害或結束規則處理。

AI 與地圖

  • AI 遇阻會後退或側移重搜，不左右抖動。
  • 固定 seed 可重現可通過的安全區與危險鏈。

挑戰模式

  • 不同 FPS 下鏡頭與老鷹觸發時間一致。
  • 老鷹開始後，停止輸入與一般傷害判定並結算。
